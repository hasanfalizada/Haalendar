- **Backlog:** [`docs/backlog/BACKLOG.md`](docs/backlog/BACKLOG.md) is the single source of tasks. Read its rules first:
  take the next task only from there (whoever it is assigned to), propose it with the reason, wait for the owner's
  confirmation, keep the status up to date, never invent tasks or take them from memory.
- **Working rules of the owner:** analysis → options with a recommendation → confirmation → work; the owner commits and
  pushes himself; every code comment carries `+++===+++ {date} — Hasan Alizada — {what}`; user content is only ever
  soft-deleted; after each task: full checks, live check, report with a Conventional Commits message.
- **How to build, run and test:** [`DEVELOPMENT.md`](DEVELOPMENT.md). Requirements and owner decisions:
  [`docs/requirements/SRS.md`](docs/requirements/SRS.md). Architecture: [`docs/architecture/`](docs/architecture/).
