# Haalendar brand assets

| File | Purpose |
|---|---|
| `logo-mark.svg` | Logo mark (app tile), any size |
| `logo-mark-mono.svg` | Single-color mark for print, embossing, monochrome contexts |
| `logo-wordmark.svg` | Mark + name, for light backgrounds |
| `logo-wordmark-dark.svg` | Mark + name, for dark backgrounds |
| `icon.svg` | SVG favicon for modern browsers |
| `favicon.ico` | Legacy favicon (16, 32, 48 px) |
| `apple-touch-icon.png` | iOS home screen icon (180 px, no transparency) |
| `icon-192.png`, `icon-512.png` | PWA manifest icons |
| `icon-maskable-512.png` | PWA maskable icon (glyph inside the safe zone) |

## Colors

| Role | Hex |
|---|---|
| Primary (teal) | `#0F766E` |
| Primary dark (hover) | `#115E59` |
| Accent (amber) — graphics only, never as text background with white text | `#F59E0B` |
| Ink (text) | `#111827` |

Wordmark typeface: [Inter](https://rsms.me/inter/) SemiBold (SIL Open Font License 1.1), converted to outlines.

## Usage

- Do not stretch, rotate, recolor or add effects to the logo.
- Keep clear space around the mark of at least 1/4 of its width.
- Minimum size: mark 16 px, wordmark 120 px wide.
