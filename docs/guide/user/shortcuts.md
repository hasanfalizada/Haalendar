# Keyboard shortcuts

the app is missing here.

`?` in the app lists the keys of the page you are on. `Mod` is `Ctrl` on Windows and Linux and `⌘` on a Mac. Single
keys do nothing while you type in a field.

## Everywhere

| Keys | What they do |
|---|---|
| `?` | Show the keyboard shortcuts |
| `Alt+1`, `Alt+2`, `Alt+3` | Go to Calendar, To-Do, Kanban |
| `/` | Search |
| `Mod+K` | Commands and search |
| `Mod+Z` | Undo |
| `Mod+Shift+Z` or `Ctrl+Y` | Redo |
| `F6` / `Shift+F6` | Next / previous area of the page |
| `Mod+S` or `Mod+Enter` | Save the open editor |
| `Esc` | Close a window, clear the selection |

## Calendar

| Keys | What they do |
|---|---|
| `Left` / `Right` | Previous / next day, week, month or range |
| `T` | Today |
| `D`, `W`, `M`, `A` | Day, week, month, agenda view |
| `N` | New event |

In the details of an event: `E` edits, `D` duplicates, `Delete` deletes, `Mod+Z` undoes it.

## Lists: the day's events, the trash

| Keys | What they do |
|---|---|
| `Up` / `Down` | Previous / next item |
| `Home` / `End` | First / last item |
| `Shift+Up` / `Shift+Down` | Extend the selection |
| `Space` | Select or unselect the item |
| `Mod+A` | Select all shown |
| `Enter` or `E` | Open the item (in the trash: restore it) |
| `Delete` | Delete the selection or the focused row (asks first) |

## To-Do and Kanban

| Keys | What they do |
|---|---|
| `Alt+Up`, `Alt+Down`, `Alt+Left`, `Alt+Right` | Move the focused note or card (on a board also to the next column) |
| `Alt+Up` / `Alt+Down` in a checklist item | Move the item |
| `Ctrl+Enter` in a comment | Send it |
